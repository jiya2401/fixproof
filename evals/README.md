# Evaluations

This directory will hold the M11 benchmark comparing:

- **Baseline:** Nemotron → patch → existing tests
- **FixProof:** Nemotron → patch → adversarial plan → execution/evidence engine → repair loop

Planned metrics:
- true fixes accepted
- incorrect fixes accepted
- regressions introduced
- counterexamples discovered
- repair iterations
- execution time
- model/token usage

Do not publish made-up benchmark numbers. Every result shown in the final demo must come from reproducible runs.
